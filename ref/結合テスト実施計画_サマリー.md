# 結合テスト実施計画 - エグゼクティブサマリー

**作成日**: 2025-11-06  
**対象システム**: Here's Me Server (三層アーキテクチャ Web アプリケーション)

---

## 📋 概要

単体テスト完了(C0: 94.86%, C1: 87.41%)を受け、外部依存性を含む結合テスト・E2Eテストを実施する。

---

## 🎯 目的

1. **外部連携の検証**: Java暗号化モジュール、AWS SSM、PostgreSQL
2. **後方互換性**: 旧クライアント(ver2.0以前)との動作確認
3. **バグ修正検証**: 単体テストで検出された不具合の修正確認
4. **E2Eシナリオ**: 実ユースケースに基づく総合動作確認

---

### 対象テストケース: 13ケース

| 優先度 | 件数 | 内容 |
|--------|------|------|
| 🔴 高 | 5 | 旧クライアント対応、バグ修正後検証、E2Eフロー |
| 🟡 中 | 6 | AWS連携、エラーハンドリング |
| ⚪ 低 | 2 | Constructor動作、外部コマンド依存 |

```

db-util.js       : AWS SSM連携、DB接続管理
whereabouts.js   : 所在情報管理
```

## ⚠️ 既知の不具合（Phase 0で修正必須）

### BUG-001: geolocation.js
- **箇所**: Line 120
- **内容**: `sectionId` 未定義エラー
- **修正**: `sectionId` → `groupId`

### Bug #1-4: user-info.js
- **Bug #1**: stderr チェックロジックが逆
- **Bug #2**: stdout チェック不足
- **Bug #3**: try-catch 未実装
- **Bug #4**: エラーメッセージ不明瞭
