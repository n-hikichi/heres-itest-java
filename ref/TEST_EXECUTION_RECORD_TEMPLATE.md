## 使用方法

### 1. テンプレートのコピー
```bash
cp ref/TEST_EXECUTION_RECORD_TEMPLATE.md test-records/IT-XXX_YYYYMMDD.md
```

### 2. 記録の作成手順
1. 「テストケースID」を実際のIDに置換
2. 「基本情報」セクションを記入
3. 「前提条件」を確認してチェック
4. 「実施内容」の各Stepを記録
5. 「エビデンス」を添付
6. 「総合判定」を記入
7. 「承認」欄に署名

### 3. ファイル命名規則
```
test-records/IT-XXX_YYYYMMDD_結果.md
例: test-records/IT-009_20251106_PASS.md
    test-records/IT-003_20251106_ExpectedFAIL.md
```

### 4. 保存場所
```
test-records/
├── phase1/
│   ├── IT-001_20251106_PASS.md
│   ├── IT-002_20251106_PASS.md
│   ├── IT-003_20251106_ExpectedFAIL.md
```
