## 1. 事前準備

### 1.1 必要なソフトウェア

| ソフトウェア | バージョン | 用途 |
|------------|-----------|------|
| Node.js | 14.x以上 | テスト実行環境 |
| npm | 6.x以上 | パッケージ管理 |
| Java | 8以上 | パスワード暗号化/復号化 |
| PostgreSQL | 12.x以上 | データベース |

### 1.2 環境構築

#### PostgreSQLのインストールと起動

**Ubuntu/Debian**:
```bash
# インストール
sudo apt-get update
sudo apt-get install postgresql postgresql-contrib

# 起動
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 確認
pg_isready
```

**macOS**:
```bash
# インストール
brew install postgresql@14

# 起動
brew services start postgresql@14

# 確認
pg_isready
```

**Docker**:
```bash
# PostgreSQLコンテナを起動
docker run -d \
  --name postgres-heresme \
  -p 5432:5432 \
  -e POSTGRES_USER=imhereadmin \
  -e POSTGRES_PASSWORD=admin555 \
  -e POSTGRES_DB=imhere \
  postgres:14

# 確認
docker ps | grep postgres-heresme
pg_isready -h localhost -p 5432
```

#### データベース作成

```bash
# PostgreSQLに接続
psql -U postgres

# データベース作成
CREATE DATABASE imhere;
CREATE USER imhereadmin WITH PASSWORD 'admin555';
GRANT ALL PRIVILEGES ON DATABASE imhere TO imhereadmin;

# 接続確認
psql -U imhereadmin -d imhere -c "SELECT 1"
```

#### スキーマ適用

```bash
# スキーマSQLがある場合
psql -U imhereadmin -d imhere < schema.sql

# または手動でテーブル作成
# (実際のスキーマに応じて調整)
```

### 1.3 Node.jsパッケージのインストール

```bash
# プロジェクトルートで実行
npm install
```

### 1.4 Java EncDec.class の配置

```bash
# util/EncDec.class が存在するか確認
ls -l util/EncDec.class

# 存在しない場合はコンパイル
# (EncDec.javaがある場合)
javac -d util EncDec.java
```

## 4. テスト実行

### 4.1 全テストの実行（推奨）

```bash
# 全テスト（Phase 1, Phase 2, Java）を実行
./ref/run-all-integration-tests.sh
```

**実行内容**:
- Phase 1: 開発環境結合テスト（IT-001~IT-010）
- Java結合テスト（IT-J001~IT-J012）
- Phase 2: 検証環境結合テスト（IT-004~IT-006）※AWS環境のみ

### 4.2 個別テストの実行

#### Phase 1のみ実行

```bash
npm test -- --config=ref/jest.integration.config.js \
  ref/telework.integration.test.js \
  ref/db-util.integration.test.js \
  ref/login-auth.integration.test.js \
  ref/geolocation.integration.test.js \
  ref/user-info.integration.test.js
```

#### 特定のテストファイルのみ実行

```bash
# IT-009: DB Util Constructor動作テスト
npm test -- ref/db-util.integration.test.js

# IT-010: Java連携認証テスト
npm test -- ref/login-auth.integration.test.js

# IT-003: Expected FAIL (BUG-001)
npm test -- ref/geolocation.integration.test.js
```

#### Javaテストのみ実行

```bash
./ref/run-java-integration-tests.sh
```

#### AWS環境でのテスト実行

```bash
# environmentType=1 を設定してAWS環境テストを実行
environmentType=1 ./ref/run-all-integration-tests.sh

# またはPhase 2のみ実行
environmentType=1 npm test -- ref/aws-ssm.integration.test.js
```

### 4.3 テスト実行オプション

```bash
# 詳細なログ出力
npm test -- --verbose ref/db-util.integration.test.js

# 特定のテストケースのみ実行
npm test -- ref/db-util.integration.test.js -t "IT-009-01"

# カバレッジレポート生成
npm test -- --coverage ref/db-util.integration.test.js
```

| テストID | テスト名 | Expected結果 | バグID |
|----------|---------|-------------|--------|
| IT-003 | グループ別位置情報取得 | ❌ FAIL | BUG-001 |
| IT-007 | パスワード変更正常系 | ❌ FAIL | Bug #1-4 |

### 5.4 テスト結果の判定基準

| 結果 | 判定 | 説明 |
|------|------|------|
| ✅ PASS | 合格 | テストが正常に成功 |
| ⚠️ Expected FAIL | 合格 | 既知バグによる失敗（想定通り） |
| ❌ Unexpected FAIL | 不合格 | 新規バグの発見（調査必要） |
| ⏭️ SKIP | - | 環境条件により未実施 |

**総合試験移行条件**:
- Expected FAIL以外のテストが全てPASS
- Unexpected FAILが0件

## 7. トラブルシューティング

### 7.1 PostgreSQL接続エラー

**エラー**:
```
psql: error: connection to server at "localhost" (::1), port 5432 failed
```

**対処**:
```bash
# PostgreSQLが起動しているか確認
sudo systemctl status postgresql

# 起動していない場合は起動
sudo systemctl start postgresql

# ポート確認
sudo netstat -tlnp | grep 5432
```

### 7.2 認証エラー

**エラー**:
```
psql: error: FATAL: password authentication failed for user "imhereadmin"
```

**対処**:
```bash
# パスワードを再設定
sudo -u postgres psql
ALTER USER imhereadmin WITH PASSWORD 'admin555';
```

### 7.3 Javaコマンドが見つからない

**エラー**:
```
Java command error. util/EncDec.class not found
```

**対処**:
```bash
# Javaがインストールされているか確認
java -version

# EncDec.classが存在するか確認
ls -l util/EncDec.class

# 存在しない場合はコンパイル
javac -d util EncDec.java
```

### 7.4 テストがタイムアウトする

**エラー**:
```
Timeout - Async callback was not invoked within the 5000 ms timeout
```

**対処**:
```bash
# タイムアウト時間を延長
JEST_TIMEOUT=60000 npm test -- ref/db-util.integration.test.js
```

### 7.5 Expected FAILが実際にPASSする

これは**バグが既に修正されている**可能性があります。

**対処**:
1. コードを確認（BUG-001, Bug #1-4が修正済みか）
2. `test.failing()` を `test()` に変更
3. 再度テストを実行してPASSすることを確認
