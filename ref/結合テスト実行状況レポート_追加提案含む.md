## IT-025: 設定ファイル結合テスト（5件）

**目的**: auth-configの結合テスト（実際の設定ファイル読み込み確認）

| IT番号 | テストケース | 観点 |
|:------|:-----------|:-----|
| IT-025-01 | 設定ファイルが正しく読み込まれる | ファイル読み込み |
| IT-025-02 | secretkeyがJWT署名に使用できる | 実際のJWT生成 |
| IT-025-03 | 複数モジュールで同じ設定が共有される | シングルトン確認 |
| IT-025-04 | 環境変数による上書き（存在する場合） | 環境変数優先 |
| IT-025-05 | 設定値の不変性確認 | Immutability |

**実装例**:
```javascript
test('IT-025-02: secretkeyがJWT署名に使用できる', () => {
  const jwt = require('jsonwebtoken')
  const authConfig = require('../../config/auth-config')

  const payload = { id: 'test_user' }
  const token = jwt.sign(payload, authConfig.secretkey)

  expect(token).toBeDefined()
  expect(token.split('.').length).toBe(3)

  const decoded = jwt.verify(token, authConfig.secretkey)
  expect(decoded.id).toBe('test_user')
})
```

**目的**: logger-wrapperの結合テスト（実際のログファイル出力確認）

| IT番号 | テストケース | 観点 |
|:------|:-----------|:-----|
| IT-026-01 | ログファイルが作成される | ファイルI/O |
| IT-026-02 | 各ログレベルが正しく出力される | レベル別出力 |
| IT-026-03 | ログフォーマットが正しい | フォーマット検証 |
| IT-026-04 | ログローテーションが動作する | ファイルサイズ管理 |
| IT-026-05 | 同時アクセス時のログ出力 | 並行処理 |

**実装例**:
```javascript
test('IT-026-01: ログファイルが作成される', () => {
  const fs = require('fs')
  const path = require('path')
  const logger = require('../../util/logger-wrapper')

  const testMessage = 'IT-026-01 test log'
  logger.sLog.info(testMessage)

  // ログファイルの存在確認
  const logPath = path.join(__dirname, '../../logs/system.log')
  const exists = fs.existsSync(logPath)

  expect(exists).toBe(true)

  if (exists) {
    const logContent = fs.readFileSync(logPath, 'utf8')
    expect(logContent).toContain(testMessage)
  }
})
```
