# 結合テストツール戦略書

**作成日**: 2025-11-06  
**対象プロジェクト**: Here's Me Server  
**バージョン**: 1.0

---

## 📋 エグゼクティブサマリー

単体テストで使用している **Jest（Node.js）** と **JUnit（Java）** を結合テストでも継続使用する。
モック機能を無効化し、実環境（PostgreSQL、Java EncDec）との統合を検証する。

---

## 🎯 ツール選定方針

### 基本原則

1. **継続性**: 単体テストと同じツールを使用（学習コスト削減）
2. **段階的実装**: Phase 0-1は手動、Phase 2以降で自動化
3. **適材適所**: レイヤーごとに最適なツールを選択

---

## 🔧 ツール構成

### 1. Node.js結合テスト: **Jest + Supertest**

#### 選定理由

| 項目 | 理由 |
|------|------|
| **継続性** | 単体テストで既に使用（Jest 29.7.0） |
| **モック制御** | `jest.unmock()` で実環境テスト可能 |
| **API テスト** | Supertest でHTTPリクエストテスト |
| **カバレッジ** | 結合テストのカバレッジ測定可能 |
| **並列実行** | `maxWorkers` で制御可能 |

#### ディレクトリ構成

```
tests/
├── unit/                    # 単体テスト（既存）
│   ├── models/
│   └── utils/
├── integration/             # 結合テスト（新規）
│   ├── setup.js            # 共通セットアップ
│   ├── telework.integration.test.js
│   ├── geolocation.integration.test.js
│   ├── login-auth.integration.test.js
│   └── user-info.integration.test.js
└── e2e/                     # E2Eテスト（Phase 3以降）
    └── login-flow.spec.js
```

#### 実行コマンド

```bash
# 結合テストのみ実行
npm test -- --config=jest.integration.config.js

# 特定のテストファイル実行
npm test -- tests/integration/telework.integration.test.js

# カバレッジ付き実行
npm test -- --config=jest.integration.config.js --coverage
```

### 2. Java結合テスト: **JUnit 5 + ProcessBuilder**

#### 選定理由

| 項目 | 理由 |
|------|------|
| **継続性** | 単体テストで既に使用（JUnit 5） |
| **タグ機能** | `@Tag("integration")` で分離 |
| **パラメタライズド** | `@ParameterizedTest` で多様なテストケース |
| **実行制御** | Maven で結合テストのみ実行可能 |

#### ディレクトリ構成

```
src/
├── main/
│   └── java/
│       └── com/micros/util/
│           └── EncDec.java
└── test/
    └── java/
        └── com/micros/util/
            ├── EncDecTest.java              # 単体テスト（既存）
            └── EncDecIntegrationTest.java   # 結合テスト（新規）
```

#### 実行コマンド

```bash
# 結合テストのみ実行
mvn test -Dgroups=integration

# または
mvn verify -Dit.test=EncDecIntegrationTest

# 全テスト実行（単体 + 統合）
mvn test
```

---

### 3. E2Eテスト: **Playwright**（Phase 3以降）

#### 選定理由

| 項目 | 理由 |
|------|------|
| **フロントエンド対応** | Vue.js アプリのテスト可能 |
| **高速・安定** | 最新のE2Eツール |
| **デバッグ機能** | トレースビューア、UI Mode |
| **並列実行** | 複数ブラウザで並列実行 |

#### 実行コマンド

```bash
# E2Eテスト実行
npx playwright test

# デバッグモード
npx playwright test --debug

# レポート表示
npx playwright show-report
```

## 🎯 テストカバレッジ戦略

### カバレッジ目標

| テスト種別 | カバレッジ測定 | 目標値 |
|-----------|-------------|--------|
| **単体テスト** | ✅ 測定する | C0: 95%, C1: 90% |
| **結合テスト** | ⚪ 測定しない | - |
| **E2Eテスト** | ❌ 測定しない | - |

### 理由

- **結合テスト**: 既に単体テストでカバレッジ測定済み
- **E2Eテスト**: コードカバレッジよりシナリオカバレッジ重視
