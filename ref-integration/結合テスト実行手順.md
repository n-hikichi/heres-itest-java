# 結合テスト実行手順（PostgreSQL + Java）

– server side –
このドキュメントでは、`heresme-sv-integration-tests.zip`を受け取った後、結合テストを実行するまでの手順を説明します。

**テスト対象**: PostgreSQL連携 + Java EncDec暗号化/復号化
**テストケース**: Node.js結合テスト（16ファイル）+ Java結合テスト（12ケース）

## 前提条件

### 必須環境

- **Git**: 任意のバージョン
- **Node.js**: v22.14.0以上
- **npm**: v10.9.2以上
- **Java**: 8以上（推奨: 11以上）
- **PostgreSQL**: 14.12
- **unzip**: コマンドが使用可能であること

### 環境確認

```bash
# 各ツールのバージョン確認
git --version
node --version
npm --version
java -version
psql --version
```

## 手順1: リポジトリのクローン

まず、heresme-cliリポジトリをクローンします。

```bash
git clone https://github.com/MicrosSoftwareInc/heresme-cli
cd heresme-cli
```

**注意**: リポジトリURLは固定です。変更しないでください。

## 手順2: zipアーカイブの展開

受け取ったzipファイルをリポジトリのルートディレクトリに配置し、展開します。

```bash
# zipファイルをリポジトリルートにコピー（既にある場合はスキップ）
# cp /path/to/heresme-sv-integration-tests.zip .

# zipファイルを展開（既存ファイルは上書きされます）
unzip -o heresme-sv-integration-tests.zip

# 展開されたファイルを確認
ls -la
```

### 展開されるファイル一覧

- **結合テストファイル (16個)**
    - tests/integration/setup.js
    - tests/integration/*.integration.test.js (15個)

- **Java結合テストファイル**
    - tests/integration/java/README.md
    - tests/integration/java/java-basic.test.sh
    - tests/integration/java/java-encdec.integration.test.js
    - tests/integration/java/java-performance.test.sh
    - tests/integration/java/run-all-java-tests.sh
    - tests/integration/java/KNOWN_BUGS.md
    - tests/integration/java/TEST_EXECUTION_REPORT.md

- **Java実行ファイル**
    - util/EncDec.java
    - util/EncDec.class

- **設定ファイル**
    - package.json
    - jest.config.js
    - Makefile
    - .env.example

- **ドキュメント**
    - INTEGRATION_TEST_GUIDE.md
    - README.md

## 手順3: PostgreSQL環境のセットアップ

### 3-1. PostgreSQLサービスの起動

```bash
# Linux
sudo systemctl start postgresql
sudo systemctl status postgresql

# または pg_isready で確認
pg_isready
```

### 3-2. テスト用データベースの作成

```bash
# PostgreSQLに接続（ユーザー: postgres）
psql -U postgres

# データベース作成
CREATE DATABASE heresme_test;

# 確認
\l

# 終了
\q
```

### 3-3. 環境変数の設定

```bash
# .env.example をコピー
cp .env.example .env

# .envファイルを編集してDB接続情報を設定
vi .env
```

**.envファイルの設定例**:

```bash
# PostgreSQL Configuration
DB_HOST=localhost
DB_PORT=5432
DB_NAME=heresme_test
DB_USER=postgres
DB_PASSWORD=your_actual_password_here

# Java Configuration
JAVA_CLASSPATH=util

# Test Configuration
NODE_ENV=test
LOG_LEVEL=debug

# AWS Configuration (Optional - ローカルテストでは不要)
AWS_SSM_ENABLED=false
```

**重要**: `DB_PASSWORD`を実際のPostgreSQLパスワードに変更してください。

## 手順4: Java環境の確認

### 4-1. Javaバージョン確認

```bash
java -version
# Java 8以上が表示されることを確認
```

### 4-2. EncDec.classの確認

```bash
# EncDec.classファイルの存在確認
ls -la util/EncDec.class

# 動作テスト
java -classpath util EncDec enc "test"
# 暗号化された文字列が表示されることを確認
```

**注意**: EncDec.classが見つからない場合は、以下のコマンドでコンパイルしてください：

```bash
cd util
javac EncDec.java
cd ..
```

## 手順5: 依存パッケージのインストール

`npm install` を実行して、必要な依存パッケージをインストールします。

```bash
npm install
```

または、Makefileを使用することもできます：

```bash
make install
```

### インストールされるパッケージ

- **本番依存パッケージ**: express, pg, aws-sdk, log4js, jsonwebtoken, moment, multer, cors 等
- **開発依存パッケージ**: jest (v30.2.0), supertest (v7.1.3)

## 手順6: 結合テストの実行

依存パッケージのインストールが完了したら、結合テストを実行します。

### 6-1. Java結合テスト実行（推奨）

```bash
bash tests/integration/java/run-all-java-tests.sh
```

このコマンドは以下のテストスイートを実行します：
- **Test Suite 1**: 基本テスト (IT-J001 ~ IT-J009)
- **Test Suite 2**: Node.js連携テスト (IT-J010)
- **Test Suite 3**: パフォーマンステスト (IT-J011 ~ IT-J012)

### 6-2. Node.js結合テスト実行

```bash
npm run test:integration
```

または：

```bash
npx jest tests/integration --verbose
```

### 6-3. 個別のテスト実行

特定のテストのみを実行したい場合：

```bash
# 基本テストのみ (IT-J001 ~ IT-J009)
bash tests/integration/java/java-basic.test.sh

# Node.js連携テストのみ (IT-J010)
npx jest tests/integration/java/java-encdec.integration.test.js --verbose

# パフォーマンステストのみ (IT-J011 ~ IT-J012)
bash tests/integration/java/java-performance.test.sh

# PostgreSQL連携テスト
npx jest tests/integration/db-util.integration.test.js
```

### 既知の不具合（テスト失敗）

以下の不具合は既知のもので、テストが失敗することが想定されています：

1. **日本語・マルチバイト文字の文字化け（高優先度）**
   - 影響: IT-J005, IT-J010-03
   - 原因: EncDec.javaで文字エンコーディング未指定
   - 回避策: ASCII文字のみのパスワードを使用

2. **不正なコマンド引数に対する終了コード（中優先度）**
   - 影響: IT-J007, IT-J010-05
   - 原因: エラー時にexit code 0を返す

3. **パフォーマンス目標未達成（低優先度）**
   - 影響: IT-J010-10
   - 原因: JVM起動オーバーヘッド（平均405.91ms vs 目標100ms）

詳細は `tests/integration/java/KNOWN_BUGS.md` を参照してください。

## トラブルシューティング

### 問題1: PostgreSQL接続エラー

```bash
Error: connect ECONNREFUSED 127.0.0.1:5432
```

**対策**:

```bash
# PostgreSQLが起動しているか確認
sudo systemctl status postgresql

# または
pg_isready

# PostgreSQLを起動
sudo systemctl start postgresql

# .envファイルの接続情報を確認
cat .env
```

### 問題2: Java EncDec実行エラー

```bash
Could not find or load main class EncDec
```

**対策**:

```bash
# EncDec.classが存在するか確認
ls -la util/EncDec.class

# 存在しない場合はコンパイル
cd util
javac EncDec.java
cd ..

# クラスパスを明示的に指定
java -classpath util EncDec enc "test"
```

### 問題3: npm installでエラー

```bash
npm ERR! peer dependencies
```

**対策**:

```bash
# 警告を無視してインストール
npm install --legacy-peer-deps

# または、package-lock.jsonを削除してから再インストール
rm package-lock.json
npm install
```

### 問題4: データベースが存在しない

```bash
Error: database "heresme_test" does not exist
```

**対策**:

```bash
# データベースを作成
psql -U postgres -c "CREATE DATABASE heresme_test;"

# 確認
psql -U postgres -c "\l" | grep heresme_test
```

### 問題5: 環境変数が読み込まれない

```bash
Error: DB_HOST is not defined
```

**対策**:

```bash
# .envファイルが存在するか確認
ls -la .env

# 存在しない場合は作成
cp .env.example .env

# 内容を編集
vi .env
```

### 問題6: Javaバージョンが古い

```bash
# Javaバージョン確認
java -version

# Java 8以上が必要です
# 必要に応じてJavaをアップグレードしてください
```

## 代替方法: zipファイルのみでテスト環境を構築

リポジトリをクローンせずに、zipファイルのみでテスト環境を構築することも可能です。

```bash
# 新規ディレクトリを作成
mkdir heresme-integration-test
cd heresme-integration-test

# zipファイルを展開
unzip /path/to/heresme-sv-integration-tests.zip

# 依存パッケージをインストール
npm install

# PostgreSQL環境をセットアップ（上記手順3を参照）
# .envファイルを作成（上記手順3-3を参照）

# テストを実行
bash tests/integration/java/run-all-java-tests.sh
npm run test:integration
```

**注意**:
- この方法では、Gitの履歴情報は含まれません
- source code（app.js, models/, routes/ など）は含まれていません
- テスト実行に必要な最小限のファイルのみが含まれています

## まとめ

### 基本的な手順（最短）

```bash
# 1. リポジトリクローン
git clone https://github.com/MicrosSoftwareInc/heresme-cli
cd heresme-cli

# 2. zipファイル展開
unzip -o heresme-sv-integration-tests.zip

# 3. PostgreSQL準備
psql -U postgres -c "CREATE DATABASE heresme_test;"

# 4. 環境設定
cp .env.example .env
vi .env  # DB_PASSWORDを設定

# 5. 依存パッケージインストール
npm install

# 6. Java結合テスト実行
bash tests/integration/java/run-all-java-tests.sh

# 7. Node.js結合テスト実行
npm run test:integration
```

### 所要時間

- **セットアップ**: 約10-15分（ネットワーク速度により変動）
- **Java結合テスト実行**: 約2-3分
- **Node.js結合テスト実行**: 約1-2分

### 期待される結果

#### Java結合テスト (IT-J001 ~ IT-J012)

- ✅ **基本テスト (IT-J001 ~ IT-J009)**: 27/32 成功 (84.4%)
- ✅ **Node.js連携テスト (IT-J010)**: 7/10 成功 (70.0%)
- ⚠️ **失敗テスト**: 8件（既知の不具合による）
  - 日本語文字化け: 4件
  - エラーハンドリング: 2件
  - パフォーマンス: 1件

#### Node.js結合テスト

PostgreSQL環境が正しくセットアップされている場合、大部分のテストが成功します。

### 成功基準

以下の基準を満たしていれば、結合テスト環境は正常です：

- ✅ IT-J001 ~ IT-J003 (基本動作) が成功
- ✅ IT-J004 (特殊文字) が成功
- ✅ IT-J006 (長いパスワード) が成功
- ✅ IT-J008 (不正な暗号化文字列) が成功
- ✅ IT-J009 (クラスパス解決) が成功
- ⚠️ IT-J005 (日本語) が失敗 ← 既知の不具合

## サポート

問題が解決しない場合は、以下の情報を添えて報告してください：

1. **実行環境情報**:
   - OS: `uname -a` または `ver`
   - Node.js: `node --version`
   - npm: `npm --version`
   - Java: `java -version`
   - PostgreSQL: `psql --version`

2. **エラー情報**:
   - エラーメッセージの全文
   - 実行したコマンド
   - .envファイルの設定内容（パスワードは除く）

3. **PostgreSQL情報**:
   - PostgreSQLサービス状態: `sudo systemctl status postgresql`
   - データベース一覧: `psql -U postgres -c "\l"`
   - 接続テスト: `pg_isready`
